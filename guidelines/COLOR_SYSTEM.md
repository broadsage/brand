# Broadsage Color System & Accessibility Standards

The Broadsage visual identity is anchored by **Palette 3 (Solar Gold & Midnight Navy)**, engineered for optical vibrancy, high-contrast dark environments, and enterprise technical gravitas.

## 2. Semantic Roles & Usage Hierarchy

1. **Midnight Navy (`#0A1128`):**
   - The foundation of all digital platforms.
   - Represents platform stability, 99.999% uptime, and night-shift developer focus.
   - Used for documentation bodies, terminal emulators, and marketing landing pages.

2. **Solar Gold Amber (`#F59E0B`):**
   - The primary brand accent and "Sage Beacon".
   - Illuminates the developer's journey through complex architectural decisions.
   - Used for primary CTA buttons, active state indicators, and key metric badges.

3. **Solar Light Gold (`#FCD34D`):**
   - Precision telemetry and iris highlights.
   - Used for warning notifications, code syntax highlights, and hover micro-interactions.

4. **Cloud Azure (`#0284C7`):**
   - Broad Vision, expansive horizons, and multi-cloud connectivity.
   - Used for hyperlinks, cloud status indicators, and secondary navigation pills.

5. **Crisp Snow White (`#FFFFFF`):**
   - The optical anchor of clarity.
   - Used for primary headings, eyeglass frame bridge, and code chevron chest markings.

## 3. WCAG Accessibility Compliance

- **Primary Text on Navy:** White (`#FFFFFF`) on Midnight Navy achieves **18.7:1**, vastly exceeding WCAG AAA standards (7:1).
- **Golden Accents on Navy:** Solar Gold (`#F59E0B`) achieves **8.4:1**, compliant with WCAG AAA for both normal and large text.
- **Light Theme Compatibility:** When operating on white backgrounds, use **Solar Gold Dark (`#D97706`)** to maintain a minimum 4.5:1 AA contrast ratio.
