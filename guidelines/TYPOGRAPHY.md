# Broadsage Typography Hierarchy & Standards

Broadsage pairs a geometric grotesque sans-serif for UI clarity with a precision monospaced typeface for developer ergonomics.

---

## 1. Primary Font Stack

```css
/* UI, Headers, and Prose */
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;

/* Code, Terminal, and Configuration */
font-family: ui-monospace, SFMono-Regular, "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;
```

## 2. Scale & Hierarchy Table

| Level | Size | Weight | Line Height | Tracking | Application |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Wordmark** | `34px` | ExtraBold (800) | `1.0` | `-0.5px` | Primary logo text lockup |

| **Code / CLI** | `13px` | Medium (500) | `1.5` | `0px` | Terminal blocks, code snippets |

## 3. The Broadsage Wordmark Construction

The wordmark is engineered with two distinct weights and colors:
- **`BROAD`**: ExtraBold 800, `#FFFFFF` (Crisp Snow White).
- **`SAGE`**: ExtraBold 800, `#F59E0B` (Solar Gold Amber).
- **Subtitle (Philosophy)**: Medium 500, `#94A3B8` (Slate 400), `Broad Vision, Sage Guidance — Open to Everyone.`
